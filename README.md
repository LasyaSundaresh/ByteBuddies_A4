# 📚 ByteBuddies_A4 – Multi-Feature AI Assistant ChatBot

ByteBuddies_A4 is a hackathon project combining **chatbot intelligence**, **sentiment analysis**, **book and music recommendations**, and **speech-to-text** functionality into a single interactive AI platform.

---

## 🚀 Features
- **Conversational AI** – Chat with BlissBot using trained deep learning models (`.h5` models and `.pkl` files).
- **Sentiment Analysis** – Detect sentiment from user inputs via NLP pipelines.
- **Book Recommender** – Suggest books based on user preferences, ratings, and popularity.
- **Music Recommender** – Recommend songs using genre and popularity data.
- **Speech to Text** – Convert spoken input into text commands.
- **Web-based Interface** – Flask templates with static assets for a user-friendly experience.

---

## 🛠 Tech Stack
- **Python 3.11**
- **Flask** – Web framework
- **Pandas / NumPy** – Data processing
- **Scikit-learn / Joblib** – Model training and loading
- **TensorFlow / Keras** – Deep learning for chatbot models
- **NLTK / spaCy** – Natural language processing
- **Matplotlib / Seaborn** – Data visualization (if used)
- **SpeechRecognition** – Speech-to-text
